**`created_by` has no foreign key.** Account deletion is a hard delete (`ProfileController::destroy`). A student subtopic is shared, so it cannot cascade with its creator, cannot block the deletion, and nulling it would make NULL mean both "catalog" and "creator gone". Chosen: no FK, like `admin_actions.subject_id`, and a check that `created_by IS NULL` exactly when `origin = 'catalog'`. Ledger entry on landing.

**"Listed" is what "starting point" meant.** The picker and all three reads in `SubtopicScopeCheck` (the catalog shown to the model, the preset short-circuit, the collision sentence) now read listed rows only. An unlisted student row is still checked by the model each time it is typed — it passed once, for someone else.

**Open for Colin:** "a link to the student" (16.1.6) has no student page to point at until 17.1.2; it links to the admin student list for now.

**Trap: `cursor()` drops eager loads, constraints included.** `CourseController::catalog()` iterated `Module::with('subtopics')->cursor()`; the `with` never ran and each module lazy-loaded its relation. Harmless until the eager load carried `listed()` — then the picker offered unlisted rows. Now `get()`. → lessons.

**`NextActionTest::a_completed_course_whose_module_is_gone_lands_on_the_dashboard` removed.** `course → subtopic → module` is now foreign-keyed, so a course cannot outlive its module; the test could not build its state. `NextAction`'s dashboard fallback for a missing module is now unreachable — package 8's code, left alone, flagged to Colin.

**`CourseFactory` resolves `subtopic_id` from its own slugs**, creating the module and an unlisted student row if the test did not seed them, so the 23 test files that use it needed no change. `CourseCatalogSeeder` now sets origin/listed/created_by, so seeding after the factory claims a catalog slug back.
